# Python Data Science, EDA, and ML Portfolio

This repository is a collection of Python-based data analysis, exploratory data analysis (EDA), and machine learning exercises built as coursework and practice projects. It demonstrates a practical, hands-on approach to working with tabular data, cleaning and validating inputs, visualizing relationships, and applying statistical and machine learning methods to real-world-style datasets.

The work in this repo is designed to show foundational skills that are valuable in data engineering, analytics, and data science roles: data wrangling, pipeline thinking, exploratory analysis, modeling basics, reproducible notebook workflows, and clear communication of results.

## Why this repository matters

This project shows progression from basic Python scripting to more advanced data work, including:

- reading and processing structured data from CSV/text files
- cleaning and validating data quality issues
- performing descriptive and exploratory analysis
- building visualizations to communicate findings
- creating simple predictive models and evaluating results
- comparing expected vs. actual outputs in coursework assignments
- working in a notebook-first workflow common in data teams

For a recruiter or hiring manager, this repo signals that the author can work with real data in a structured, methodical manner and can translate raw files into analytical insight using Python.

## Repository structure

The repo is organized by topic and assignment, with folders such as:

- hw1 through hw8: weekly homework assignments covering Python programming, data analysis, and modeling concepts
- proj1: a larger project with input/output files and validation-style checks
- lect02 through lect16: lecture exercises and notebooks on core data science topics
- exam1: review material and course-related work
- resources: supporting materials and project assets

This layout reflects a progressive learning path from fundamentals to applied analysis and modeling.

## How to run this project

1. Create a virtual environment:

   python -m venv .venv

2. Activate it:

   - Linux/macOS: source .venv/bin/activate
   - Windows: .venv\Scripts\activate

3. Install dependencies:

   pip install -r requirements.txt

4. Open the notebooks in Jupyter or VS Code and run the analysis cells.
